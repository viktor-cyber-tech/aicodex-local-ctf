# Responsible Use Policy

AICodex is an educational local AI setup for cybersecurity learning, authorized CTFs, homelabs, defensive analysis, and lawful research.

## Allowed use

Use this repository only on systems, applications, networks, accounts, and data that you own or have explicit written authorization to assess. Examples include:

- Personal labs and homelabs
- Classroom exercises and approved training platforms
- Capture-the-flag competitions
- Authorized security assessments with a defined scope
- Defensive monitoring, analysis, and remediation

## Prohibited use

Do not use this repository, its scripts, or its model configuration to:

- Access, scan, exploit, disrupt, or degrade a system without authorization
- Steal credentials, data, funds, identities, or access
- Create, distribute, or operate malware, ransomware, phishing, or evasion tooling
- Harass, surveil, or harm people or organizations
- Violate applicable law, contracts, platform rules, or a security-testing scope

## User responsibility

You are solely responsible for determining whether you have authorization, selecting targets, handling data, and complying with applicable law. The author does not monitor, control, endorse, sponsor, employ, or affiliate with users of this repository.

## Reporting

If you believe this repository is being used or represented in a way that conflicts with this policy, open a GitHub issue without posting sensitive data. The author may remove or restrict project content at their discretion.
